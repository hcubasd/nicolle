# Previous coursework interface

Preserved source and material for the old roadmap, Kruskal laboratory, rescue prototype and Python tutorial. This directory is excluded from the active TypeScript project and Vite entry point. It is a reference archive, not a separate configured application.

`PROJECT-README.md` describes the previous project. The original deployed version can be recovered from Git commit `0d3b1e6`. The source snapshot here also preserves the subsequent local background update that preceded the canonical Nicrainha engine.

The new interface uses Prim and generated maps. The original Python examples are historical and are not linked or shipped as current game instructions.
